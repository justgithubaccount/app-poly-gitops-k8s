## IMPLEMENT

Use existing version-pinned Helm Applications through dev overlays. Publish only
`argo.syncjob.ru`, `grafana.syncjob.ru`, `chat-dev.syncjob.ru`; retain the
standalone app Ingress owner to avoid chart duplicates. Issue certificates per
namespace using ingress-shim; render the issuer through cert-manager extraObjects
after operator readiness. Require fresh Cloudflare secrets in cert-manager and
external-dns rather than cluster-bound SealedSecrets or reflector.

Protect the public FastAPI with HTTP basic authentication and use a stable
externally created Grafana admin Secret. DNS is ingress-only, zone/annotation-filtered, TXT-owned and
upsert-only. Do not publish OpenWebUI, CrewAI, Loki or Vector.

Existing ingress-nginx is retired upstream; retaining it is a temporary legacy
restoration, not a recommendation for a new permanent public deployment. Document
this limitation and the fact that an external LoadBalancer may incur cloud costs.
